# Retrospectives

One file per project or goal, written by the Chief of Staff as the final step of
the pipeline. Each retro records what went well, what went badly or needed
rework, and the ranked improvement actions (skills, MCPs, new or changed agents,
documentation). Improvement actions that get adopted turn into real changes to
`.claude/`, `docs/`, or `CLAUDE.md`.

Suggested shape:

```
# Retro: <project or goal>

## Outcome
What shipped, against what the brief asked for.

## What went well
...

## What went badly / needed rework
...

## Improvement actions (ranked)
1. <skill / MCP / agent / doc change> - why, evidence, rough effort.
```
